FAQ_ROW|personal-data|001|status=publicada
P: Quais dados podem ser corrigidos no autosserviço?
R: Telefone corporativo e endereço de correspondência podem ser solicitados no Farol; dados bancários usam validação reforçada.

FAQ_ROW|personal-data|002|status=publicada
P: Posso mandar um dado bancário no chat?
R: Não. Use o fluxo protegido do Farol.

FAQ_ROW|personal-data|003|status=publicada
P: Qual canal usar para solicitar correção em dados bancários?
R: Em dados bancários, não envie o valor pelo chat. Quando necessário, People Data usa Farol para solicitar correção.

FAQ_ROW|personal-data|004|status=publicada
P: O estado rascunho conclui nome cadastral depois de solicitar correção?
R: Depois de solicitar correção, People Data confere nome cadastral no estado rascunho. não envie o valor pelo chat.

FAQ_ROW|personal-data|005|status=publicada
P: O que acontece depois de solicitar correção para contato de emergência?
R: Não por si só. Para contato de emergência, People Data valida no Farol antes de solicitar correção; não envie o valor pelo chat.

FAQ_ROW|personal-data|006|status=publicada
P: Há limite ao solicitar correção para documento de identidade?
R: O registro de documento de identidade segue pelo Farol para solicitar correção. não envie o valor pelo chat; People Data confirma o próximo estado.

FAQ_ROW|personal-data|007|status=publicada
P: Como acompanhar a validação para endereço de correspondência no estado rascunho?
R: People Data acompanha endereço de correspondência pelo Farol para acompanhar a validação. Enquanto estiver rascunho, não envie o valor pelo chat.

FAQ_ROW|personal-data|008|status=publicada
P: Quem trata telefone corporativo ao acompanhar a validação no estado rascunho?
R: Para telefone corporativo, use Farol ao acompanhar a validação; People Data trata o caso. não envie o valor pelo chat.

FAQ_ROW|personal-data|009|status=publicada
P: Qual canal usar para acompanhar a validação em dados bancários?
R: Em dados bancários, não envie o valor pelo chat. Quando necessário, People Data usa Farol para acompanhar a validação.

FAQ_ROW|personal-data|010|status=publicada
P: O estado rascunho conclui nome cadastral depois de acompanhar a validação?
R: Depois de acompanhar a validação, People Data confere nome cadastral no estado rascunho. não envie o valor pelo chat.
